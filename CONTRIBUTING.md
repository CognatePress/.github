# Contributing

Cognate Press is an imprint, not a platform. That shapes what contribution means
here, so this file says plainly what is and is not accepted.

## Writing

**Guest submissions are not accepted.** Every publication carries exactly one
byline, and that byline works in the language it writes about. There is no
submission queue, no pitch address, and no path by which an article written by
someone else appears under a title's name. This is not a backlog — it is the
policy the imprint exists to hold.

Nothing published is paid for: no sponsored posts, no affiliate links, no vendor
writing about its own product under a byline. Offers of any of these are declined.

## Corrections

Corrections are the contribution the imprint actively wants.

A claim that turns out to be wrong is corrected on the page that made it, carrying
the date and the evidence that changed it. Nothing is quietly rewritten.

To report one, write to the publication that carried the claim. Each title answers
at `contact@` its own domain — the domain the article is on. Include:

- the article, and the sentence or figure as published;
- what is wrong with it;
- the evidence: the source, the version, the machine, the command, and the output
  it produced. A correction is held to the same standard as the claim it corrects.

A reproduction short enough to read is worth more than a description of one.

## Code

Where a repository in this organization takes changes, the same standard applies to
the commit message as to an article: say what changed and why, and let a claim about
behaviour arrive with the means to check it. Pinned versions, pasted output, and a
command someone else can run.

## Anything else

Rights, press, the newsletter, and anything about the imprint as a whole:
**contact@cognate.press**.
